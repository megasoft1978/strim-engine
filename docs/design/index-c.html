Install

Up in three commands.

  1. Install

    brew install megasoft1978/strim/strim

    Homebrew first. The curl script does the same.

  2. Pull the model

    strim pull

    Pinned revision, resumable, verified.

  3. Serve

    strim serve

    Point Claude Code or Codex at the local port.

FAQ

Questions.

Which model does it run?

Qwen3.8-27B in 4-bit, with the MTP head, on Apple silicon.

Which clients work?

Claude Code and Codex are the targets: Strim is a local backend that behaves like a server.

How were the numbers measured?

Apple M5 Max, 64 GB, same prompts for every engine, one engine on the GPU at a time. Raw files are in bench/results.
