Open `index-a.html`, `index-b.html`, `index-c.html` (dark and light follow the OS). Screenshots: `shots/` (`<k>-1280-top|full-dark|light.png`, `<k>-390-...`). Marks: `logo-*.svg`. README banners 1280x640: `banner-*.svg`, README drafts: `readme-*.md`.

## Research (headless screenshots 1280x900 plus page reads, 2026-10-28)
1. https://bun.sh : the speed proof sits IN the hero as a tabbed card (bun install / Express / ...): one hot-pink bar with the mascot riding the end, grey rivals, a 22px mono value (0.21s), a methodology footnote and a "reproduce" link. Install box has OS tabs and a copy icon. Honest footnote is part of the premium feel.
2. https://esbuild.github.io : the whole identity is one tiny bar chart, one yellow bar against grey ones, 100x ratio visible at a glance, caption states the exact workload.
3. https://turborepo.com : hero is a speedometer dial with a blue-to-red arc, then a gradient-filled giant stat row (17,919,703). Install is a dark pill `$ npm i turbo` with a copy icon. Numbers are the imagery.
4. https://vercel.com : pure black, a single grain-lit mark, 64px tight-tracked grotesk, enormous negative space, two pill CTAs. Restraint reads as confidence.
5. https://linear.app : near-black (#08090A feel), headline ~64px with tight tracking, hairline 1px borders, product UI cropped off the fold, no accent colour at all in the hero.
6. https://vite.dev : hairline grid frames, install as tabs (npm/Yarn/pnpm/Bun/Deno) over a mono line, purple used only for state (active tab, focus ring).
7. https://zed.dev : serif display plus mono body (editorial), "Est 2021" micro-labels, metallic logos in hatched tiles, real product screenshots in window chrome.
8. https://cursor.com : warm brown-black (#14120B-like) instead of cold black, a painting as backdrop, cream pill CTA, product frame as the hero.
9. https://raycast.com : floating glass nav pill, two-line centered headline, "Install via Homebrew" text link directly under the primary CTA (Homebrew-first convention).
10. https://ghostty.org : the logo shown in terminal window chrome, ASCII rendering, almost no copy; personality from one idea.
11. https://ollama.com : white, 3 stat numerals, a line-drawn mascot; proof that a plain page works when the mark is memorable.
12. https://tailscale.com : off-white paper, dot-grid logo, large humanist sans, coloured feature tiles.
13. GitHub README of astral-sh/uv (https://github.com/astral-sh/uv): leads with the one-line claim and a single benchmark image (commit "Add top-level benchmark to the README" visible in the tree); the README hero image is one chart plus one line.
Not captured this pass: Arc, Resend, Warp, Apple silicon pages (blocked or redirected in headless). Patterns that make it premium: (a) one accent colour used for the winner only; (b) type 56-160px with -3 to -5% tracking against 12-14px mono labels; (c) hairlines instead of boxes; (d) the speed visual is the hero or sits directly under it with exact workload text; (e) install = tabbed mono box with copy; (f) motion is one slow reveal (bars growing), never looping; (g) warm or tinted blacks beat #000; (h) the mark is simple enough for a 16px favicon.

## Design system (shared)
Scale 12/14/17/21/32/56/clamp(56-160). Mono for labels, numbers and commands; display face carries the numerals. 8px grid, 1px hairlines (2px in B). One accent per direction, never green; losses use muted ink with a dashed or struck treatment and the label "honest loss". Motion: single 1.2s grow-in, disabled under prefers-reduced-motion. Install box: tabs (Homebrew first, curl second) + Copy; steps then `strim pull`, `strim serve`. Breakpoint 860px; every chart is generated twice (wide and 360-wide) so type never shrinks below 11px at 390.

## Directions
**A Ember editorial** (`index-a.html`, `logo-a.svg`, `banner-a.svg`). Warm black #14110E, panel #1D1813, text #F5EEE2, muted #A89B89, amber #F2A93B to ember #FF6A2B; light: paper #F7F0E4, ink #1E1812, accent #C8650C. Instrument Serif (display, italic accent word), Geist, Geist Mono; subtle SVG grain. Speed visual: race lanes, a comet trail slides to each engine's tok/s with a 64px serif numeral for Strim. Ratios as a typographic ledger (struck-through grey for losses). Mark: a continuous S sliced by two diagonal cuts (stream trimmed into tokens), amber app icon.
**B Swiss paper** (`index-b.html`, `logo-b.svg`, `banner-b.svg`). Paper #F5F2EB, ink #0F0F0E, vermilion #EE3B22; dark: #0E0E0D, #F3F0E8, #FF5A3F. Inter Tight 800 at -4.5% tracking, IBM Plex Mono; 12-column grid, 2px rules, section indexes 01-07. Speed visual: a 68.3 numeral at 236px, then a skyline of 8 towers with Strim in vermilion; ratios on a log "dial strip" around a 1.0x line, two dots per metric joined by a whisker (losses fall left of the line). Mark: blocky S from three bars and two joins with slanted trimmed ends, vermilion tile; the clearest at 16px.
**C Aurora glass** (`index-c.html`, `logo-c.svg`, `banner-c.svg`). Night #0A0920, panel #12102E, text #F1EFFF, muted #A29FC8, gradient #6E6BFF > #B25CFF > #FF4FD0; light: #F6F4FF, #15123A, #4F4BFF/#9240FF/#E0309E. Space Grotesk, JetBrains Mono; glass cards, blurred glow. Speed visual: all 8 engines as beads on one number line, Strim a glowing orb at 68.3; ratios as glass cards with 1.0x-anchored arc gauges. Mark: glowing S made of four token capsules on a navy tile.

## Recommendation: B (Swiss paper)
It is the only one that looks unlike every dev-tool landing page (all dark with glow), it makes the product's single claim, a number, the hero, and its two data visuals (tower, dial strip) show wins and losses with equal clarity, which fits the honest-loss stance. It prints well as a README banner, survives GitHub's light and dark themes, has the strongest 16px mark, and the vermilion is far from the green the owner dislikes. A is the fallback if more warmth is wanted (serif is the most premium, but lanes are close to a bar chart). C is the most generic of the three.
