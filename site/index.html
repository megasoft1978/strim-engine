What is inside

Speculative decoding

A built-in MTP head drafts several tokens per step and the full model verifies them. 65% of drafted tokens were accepted in the 4K prefix-cache run.

Exact prefix cache

Agents that share a prompt prefix reuse its computed state, so the repeated part is not read again. A 4K prefix hit returned the first token 3.91x sooner.

Install

Apple Silicon, macOS 14 or newer. The app downloads the model on first launch; with the command line, strim pull does it. Tested on Apple M5 Max, 64 GB.

$ brew install megasoft1978/strim/strim
$ strim pull

# optional: menu-bar app, includes the CLI

$ brew install --cask megasoft1978/strim/strim-app

Installs the strim command, then downloads the model.

$ curl -fsSL https://raw.githubusercontent.com/megasoft1978/strim-engine/main/packaging/install.sh | bash
$ strim pull

No sudo. Installs to ~/.local/strim and links ~/.local/bin/strim. Checks the SHA-256 before installing.

Download the DMG (arm64)Open the DMG. Drag Strim to Applications. Launch Strim from the menu bar.

Not notarized yet: right-click → Open the first time. macOS warns on first launch. Right-click Strim in Applications and choose Open, or click Open Anyway in System Settings, Privacy and Security, or run xattr -dr com.apple.quarantine /Applications/Strim.app. Homebrew avoids the warning.

Questions

Why only one model?

Everything is tuned for one dense model: its attention state, its speculative-decoding head and its prefix cache. That is why these numbers are possible, and why Strim will not run your other models. Others are on the roadmap.

Does it run on a 32 GB Mac or an M1?

Only a 64 GB M5 Max has been tested. For 32 GB the computed estimate is 114K/214K (low) 154K/291K (high) of context (not measured); 16 GB and below are unsupported. See supported scope.

Does speculative decoding change the output?

Draft tokens are verified by the full model, but batching can flip near-tie tokens. Greedy output over 8 fixed prompts and 64 tokens: Strim against itself 8/8 identical, against rapid-mlx 7/8, against mlx-vlm 6/8, against mlx-lm 6/8, against oMLX 7/8. Quality and exactness.

Does anything leave my Mac?

No prompts or files do. The server binds 127.0.0.1 only and requires a bearer token. The one network step is the model download from Hugging Face, with strim pull or on first launch of the app.

How much memory does it need?

Measured peak over the whole benchmark run: 30.8 GB on Apple M5 Max, 64 GB (rapid-mlx, mlx-vlm and mlx-lm peaked at 35.9 to 37.5 GB). For 32 GB the computed estimate is 114K/214K (low) 154K/291K (high) of context, not measured; 16 GB and below are unsupported.

Why use Ollama or LM Studio instead?

Use them if you want many models or a model browser: Strim runs one model, tuned for agent work. The current benchmark does not include them, so no comparison is claimed. See supported scope.

Is the DMG notarized?

Not yet. The first time, right-click Strim in Applications and choose Open. Installing with Homebrew avoids the warning.
